# PatMax 2D

传统 2D 边缘梯度形状匹配实验程序。支持图像内平移、平面旋转、等比例缩放和多目标查找；不使用深度学习或 3D 姿态信息。

## 构建

本机已安装的 Qt 5.15.2、OpenCV 4.8.0、Visual Studio 2022 可使用：

```powershell
cmake -S . -B build-vs -G "Visual Studio 17 2022" -A x64 `
  -DCMAKE_PREFIX_PATH="D:/Qt/5.15.2/msvc2019_64" `
  -DOpenCV_DIR="D:/opencv4.8.0/opencv/build/x64/vc16/lib"
cmake --build build-vs --config Release
$env:PATH="D:\Qt\5.15.2\msvc2019_64\bin;D:\opencv4.8.0\opencv\build\x64\vc16\bin;$env:PATH"
ctest --test-dir build-vs -C Release --output-on-failure
```

Qt Creator 未填写 `OpenCV_DIR` 时，项目会默认查找本机的 `D:/opencv4.8.0/opencv/build/x64/vc16/lib`。若已有构建目录缓存了其他版本的 `OpenCV_DIR`，请在 Qt Creator 的 CMake 配置中将其改为上述路径后重新配置。

运行 GUI 前，需让 Windows 找到 Qt 和 OpenCV 运行库。可双击 `run.cmd`，或在 PowerShell 中执行：

```powershell
.\run.ps1
```

## 使用

打开模板图像，在左侧图上拖动鼠标框选目标；打开待测图像，点击“建立轮廓模型”和“查找目标”。“加载 HALCON rings 示例”会载入 `rings_01.png` 的齿形环作为模板及 `rings_06.png` 作为待测图。

建模选用 Canny 边缘点和对应 Sobel 梯度方向，并按空间距离抽取分布均匀的特征点。搜索图在最粗层生成量化梯度方向响应图，扫描旋转、尺度和位置；候选峰值逐层细化，最后按重叠率抑制重复结果。细层使用单张 32 位方向位图及查找表评分，避免为每个方向保存一张完整响应图。分数为模板边缘处的方向响应平均值；结果窗口显示中心坐标、角度、尺度和分数。

掩膜可选，尺寸须与模板整图或框选 ROI 相同。白色区域参与建模，黑色区域排除。角度按图像坐标方向显示；对近似旋转对称的目标，多个角度可能代表同一位置。

当前精定位以像素网格为单位。实际可靠性和耗时应针对目标图像、遮挡程度及允许误差单独测量。

## 搜索速度

粗层扫描先把每个姿态的方向响应地址和像素偏移算好，搜索时直接读取；随后按图像行并行扫描，各线程只写自己的行。细层按候选并行评分，每个线程只修改自己的候选。Canny 复用已计算的 Sobel 梯度，避免重复求导。`SearchStats` 记录图像准备、粗层扫描、细化、总耗时及各细层的耗时和候选数量。

本机 Release 构建在 HALCON rings 示例上的单张搜索从约 63–70 ms 降到约 11–15 ms；实际耗时会随图像尺寸、姿态范围、特征点数和 CPU 线程数变化。

大图实测：模板 `3_03.png`、待测图 `3_07.png`，尺寸均为 4024×3036，模板 ROI 为 `(2867, 1981, 257, 460)`。在这台机器的 Release 构建上，设“最多金字塔层”为 5、“最小尺度”和“最大尺度”均为 1 时，完整模式约 138 ms；其中原图细层的全图预处理约 91 ms。勾选“快速细化”后约 21 ms，定位中心均为 `(2995, 2211)`，角度均为 0°，分数均为 `0.723172`。耗时是单次实测值，受机器负载影响。

“快速细化”在靠近原图的两层筛除低分候选；候选不超过 24 个时，只在候选附近计算边缘方向。它可能漏掉粗层分数低、细层分数高的弱目标，所以默认关闭；需要高召回率时请使用完整模式，并用实际样本评估两者差异。局部模式的预处理耗时计入细化耗时，而非响应图准备耗时。

金字塔层数是上限，并不保证每个模板都能建立这么多层。这块 257×460 的 ROI 可建立 5 层；设置最大 6 层时仍只建立 5 层，因为继续缩小后轮廓特征不够稳定。层数更深也可能降低召回率。上述 4K 图片尚未达到约 10 ms；若生产线能确定目标的大致出现区域，缩小待测范围是下一项值得验证的优化。

可用基准程序复测当前图片，最后添加 `--fast` 测试快速细化；再添加 `--explain` 可统计最优匹配的特征点响应、无边缘点数和邻近边缘距离：

```powershell
.\build-vs\Release\patmax_bench.exe "<模板图片路径>" "<待测图片路径>" 2867 1981 257 460 --fast --explain
```

## 修改界面与代码

用 Qt Designer 打开 [`src/MainWindow.ui`](src/MainWindow.ui)，可直接修改窗口布局、控件文字、参数范围和默认值。保存后重新构建，CMake 会调用 `uic` 生成 `build-vs/generated/ui_MainWindow.h`；不要手工修改生成的头文件。

界面事件及图像加载位于 `src/MainWindow.cpp`，图像坐标换算、ROI 拖选和匹配叠加显示位于 `src/ImageView.cpp`，梯度边缘建模与搜索位于 `src/ShapeMatcher.cpp`。UI 中的两块图像视图是提升为 `ImageView` 的自定义控件，修改对象名后需同步更新 `MainWindow.cpp` 中的引用。
